# Support and Contact

| You need help with | Where to go |
| :--- | :--- |
| A project brief, services, or a business inquiry | Email [usluyapimorg@gmail.com](mailto:usluyapimorg@gmail.com). |
| A bug or question about a specific project | Read that repository's README and support instructions. Use its issue tracker if invited to do so. |
| An error in this GitHub profile | Open a **Profile or documentation issue** in this repository. |
| A proposed external contribution | Open a **Contribution proposal** or email the team before implementation. |
| A vulnerability or exposed information | Follow [SECURITY.md](SECURITY.md) and report privately. |
| A conduct concern | Follow the private reporting route in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |

For technical questions, describe what you expected, what happened, and the relevant environment. Use sanitized examples. Do not post client data, hosting credentials, mail server passwords, mailbox contents, or production configuration containing secrets.

Public issues help us coordinate repository work. For client-specific requests, delivery timelines, or service arrangements, contact the team directly by email.
